# Release plan

Releases follow phase exit criteria rather than fixed dates. Phases 0–2 form the
current validated baseline. Near-term planning selects Phase 3 symbol-library work
before broader Designer Engine delivery. Later releases are gated by the
dependencies and exit criteria in each phase specification.

Release candidates require passing formatting, lint, typecheck, unit/integration
tests, relevant browser tests, build, documentation-link checks, and a recorded
risk review.
