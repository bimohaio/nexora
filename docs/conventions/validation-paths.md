# Validation paths

Validation paths use JSON Pointer, rooted at the empty string. Examples: `/nodes/3/transform/width`, `/connections/2/source/nodeId`, and `/layers/0/name`. Array indexes are decimal. Codes, not messages, are the stable machine-readable contract.
