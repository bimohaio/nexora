# Naming

Use English throughout. Classes, interfaces, and types use PascalCase; functions and variables use camelCase; constants and error codes use UPPER_SNAKE_CASE. Files, folders, packages, custom elements, and event names use kebab-case. Interfaces have no `I` prefix.
