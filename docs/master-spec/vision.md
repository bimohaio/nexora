# Vision

Nexora is a framework-independent, TypeScript SCADA framework for building
validated process documents, deterministic visualizations, design tools, and
runtime integrations. The framework favors explicit contracts, immutable design
state, replaceable infrastructure, and package boundaries that can evolve without
coupling the SCADA Core to browsers or protocols.

The long-term system consists of SCADA Core, Renderer, Designer Engine, Runtime
Engine, Binding Engine, and Plugin SDK capabilities. Delivery is incremental:
completed behavior is documented separately from future phase intent.
