# Project roadmap

Phases 0–2 are complete: workspace foundation, SCADA Core, and SVG Renderer.
Phases 3–15 progressively cover the symbol library, Designer Engine, editing,
Runtime Engine, interaction, Binding Engine, data sources, animation, history,
import/export, Plugin SDK, performance, and production readiness.

Detailed sequencing is maintained in the phase specifications and release plan.
Future phase content describes intent and is not evidence of implementation.
