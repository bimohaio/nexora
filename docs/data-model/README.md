# Data model

This folder documents persisted SCADA document entities and renderer-facing model
contracts. SCADA Core TypeScript exports remain the authoritative executable
contracts.

Start with [SCADA document](scada-document.md), then follow entity-specific pages.
Render invalidation and symbol rendering describe derived, non-persisted concerns.
