# Industrial symbol gallery

The Phase 3 gallery groups every registered symbol by category and shows live SVG
previews, normalized ports, editable properties, default/minimum sizing, and
runtime-state variants.

```bash
pnpm --filter @web-scada/symbol-gallery dev
```
